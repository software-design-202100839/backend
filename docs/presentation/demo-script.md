# 라이브 데모 시나리오 (2분)

> 발표 슬라이드 6에서 실행. 사전에 데이터 시드 + 임베딩 시드 완료 상태에서 진행.
> 시간이 부족하면 1→3→6만 보여주기.

---

## 사전 준비 (발표 30분 전)

```bash
# 1. 헬스체크
curl -sf http://<ALB_DNS>/actuator/health

# 2. 프론트엔드 접속 확인
https://<CloudFront_Domain>

# 3. Grafana 접속 확인
http://<ALB_DNS>/grafana/ (admin/admin)

# 4. 시드 데이터 확인 (로그인 되는지)
teacher@sscm.dev / teacher1234

# 5. 임베딩 시드 확인 (RAG 검색이 되려면 필수)
# admin@sscm.dev / admin1234 로 로그인 후:
curl -X POST http://<ALB_DNS>/api/v1/dev/seed/embeddings \
  -H "Authorization: Bearer <ADMIN_TOKEN>"
# 결과: feedbackEmbeddings=544, counselingEmbeddings=271
```

---

## 데모 1: 핵심 기능 (40초)

**교사 로그인** → `teacher@sscm.dev / teacher1234`

> "교사 계정으로 로그인하겠습니다."

**대시보드** → 인사말, 통계 카드, 빠른 접근

> "대시보드에서 전체 현황을 볼 수 있습니다."

**성적 관리** → 사이드바 클릭 → 학생2 선택 (Drawer)

> "학생을 선택하면 우측 Drawer에서 검색할 수 있고, 선택하면 6학기 성적과 레이더 차트가 표시됩니다."

---

## 데모 2: 분석 대시보드 (30초)

**분석 탭** → 학생2 선택

> "분석 대시보드에서 이 학생의 종합 현황을 봅니다."

**요약 탭** → KPI 카드 (평균, 위험도 MEDIUM, 추이 DOWN)

> "이 학생은 평균 68점, 위험도 MEDIUM, 하락 추세입니다."

**성적 탭** → 6학기 추이 차트

> "2024년 1학기부터 2026년 2학기까지 6학기 추이를 볼 수 있습니다. 점수가 89점에서 61점으로 지속 하락하고 있어서 주의가 필요합니다."

---

## 데모 3: AI 챗봇 (40초) ⭐ 임팩트 최대

**우하단 채팅 버블 클릭**

> "AI 학습 도우미입니다."

**입력**: "학생2의 상담 내역을 알려줘"

> "학생 이름으로 질문하면, AI가 자동으로 학생을 검색하고 데이터를 조회합니다."

*(AI 응답 대기 2~3초)*

**입력**: "걔 성적은 왜 떨어지고 있어?"

> "이전 대화를 기억하기 때문에 '걔'라고만 해도 같은 학생의 성적 추이를 분석합니다."

*(AI 응답 — 하락 추세 분석)*

> "이렇게 교사가 자연어로 질문하면 실제 데이터 기반으로 답합니다."

---

## 데모 4: 멀티테넌시 격리 (20초)

> "다중 학교 격리를 보여드리겠습니다."

**터미널에서 curl 실행** (미리 준비):
```bash
# 한빛중 교사로 새별중 학생 접근 시도
curl -s "http://<ALB>/api/v1/grades/students/2?year=2026&semester=1" \
  -H "Authorization: Bearer <한빛중_교사_토큰>" | python3 -m json.tool
```

> "한빛중학교 교사가 새별중학교 학생 데이터에 접근하면, 403 Forbidden이 반환됩니다. 교차 학교 접근이 완전히 차단됩니다."

---

## 데모 5: RAG 의미 검색 (30초)

> "이번에는 의미 기반 검색입니다."

**입력**: "2026년 1학기 수업 태도 문제 있는 학생 찾아줘"

> "단순 키워드가 아니라 의미가 유사한 피드백을 벡터 검색합니다. pgvector로 임베딩된 544건의 피드백에서 코사인 유사도 기반으로 검색합니다."

*(AI 응답 — 유사도 0.76, 학생13 발표 참여 부족 등)*

> "유사도 점수와 함께 관련 학생과 피드백 내용이 나옵니다."

---

## 데모 6: 학기말 종합 의견 생성 (40초) ⭐

> "교사가 가장 시간 쓰는 업무입니다."

**입력**: "학생2 종합 의견 작성해줘"

> "Function Calling으로 성적을 수집하고, RAG로 피드백·상담 텍스트를 찾고, LLM이 초안을 생성합니다."

*(AI 응답 + 파란 보고서 카드 표시)*

> "보고서 카드가 나타났습니다. 초안 본문, AI 초안 경고 문구, 그리고 참고 근거를 펼쳐보면 피드백 3건과 상담 2건이 근거로 사용된 걸 확인할 수 있습니다."

**"수정하기" 클릭 → 텍스트 수정 → "교사 수정본 저장" 클릭**

> "교사가 초안을 검토하고 수정하면 Human-in-the-Loop으로 저장됩니다. 수정 거리를 기록해서 AI 품질을 추적합니다."

---

## 데모 7: 대시보드 위험 알림 (20초)

> "대시보드로 돌아가면, AI 위험 알림 섹션이 있습니다. Kafka Consumer가 성적 급락이나 부정 피드백 누적을 감지하면 교사에게 자동으로 알림을 보냅니다."
