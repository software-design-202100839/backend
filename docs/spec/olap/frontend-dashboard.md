# 프론트엔드 분석 대시보드

> 작성일: 2026-05-24
> 상태: 완료 (AI 챗봇 위젯은 비활성 상태, Phase 5 후 연결 예정)

## 목표

백엔드 OLAP API를 호출하여 학생 학습 현황을 시각적으로 보여주는 대시보드 UI를 구현한다.

## 왜 이 작업이 필요한가?

백엔드 API만으로도 데이터 조회는 가능하지만, 교수님 요구사항에 "대시보드에서 조회할 수 있도록"이라고 명시되어 있고,
시연 시 Swagger보다 실제 화면이 훨씬 임팩트 있다.

---

## 추가된 페이지

### 1. 학생 분석 대시보드 (/analytics)

**접근 권한**: 모든 역할 (교사=전체 학생, 학생=본인, 학부모=자녀)

**구성 요소**:
```
┌─────────────────────────────────────────────────────┐
│  학생 선택 + 학년도/학기 필터                         │
├─────────┬─────────┬──────────────┬──────────────────┤
│ 평균점수 │ 위험도   │ 피드백/상담  │ 출결/수상        │
│ 80.2    │ 양호    │ 3/2         │ 0/0              │
├─────────┴─────────┴──────────────┴──────────────────┤
│  성적 요약 카드 (총점, 평균, 최고, 최저, 평균등급)     │
├─────────────────────────────────────────────────────┤
│  성적 추이 라인 차트 (학기별 평균 변화)               │
├─────────────────────────────────────────────────────┤
│  출결/기록 현황 (출결, 수상, 봉사, 세특, 종합의견)    │
├────────────────────────┬────────────────────────────┤
│ 피드백 카테고리 도넛차트 │ 상담 카테고리 도넛차트      │
├────────────────────────┴────────────────────────────┤
│  AI 챗봇 위젯 (준비 중)                              │
└─────────────────────────────────────────────────────┘
```

**호출하는 API** (6개를 Promise.all로 병렬 호출):
- `GET /api/v1/analytics/students/{id}/dashboard`
- `GET /api/v1/analytics/students/{id}/score-summary`
- `GET /api/v1/analytics/students/{id}/score-trend`
- `GET /api/v1/analytics/students/{id}/attendance-summary`
- `GET /api/v1/analytics/students/{id}/feedback-summary`
- `GET /api/v1/analytics/students/{id}/counseling-summary`

### 2. 과목 통계 (/analytics/subjects)

**접근 권한**: 교사, 관리자만

**구성 요소**:
```
┌─────────────────────────────────────────────────────┐
│  학년도/학기 필터                                     │
├─────────────────────────────────────────────────────┤
│  과목별 점수 비교 바 차트 (평균/최고/최저)            │
├─────────────────────────────────────────────────────┤
│  과목별 상세 통계 테이블                              │
│  (과목, 학생수, 평균, 최고, 최저, 표준편차, 등급분포)  │
├─────────────────────────────────────────────────────┤
│  선택한 과목의 등급 분포 바 차트 (A/B/C/D/F)          │
└─────────────────────────────────────────────────────┘
```

**호출하는 API**:
- `GET /api/v1/analytics/subjects/statistics`

### 3. AI 챗봇 위젯 (비활성)

- 대시보드 페이지 하단에 배치
- "준비 중" 표시, 입력 비활성
- Phase 5 (백엔드 AI 챗봇 API) 완성 후 연결 예정
- 호출할 API: `POST /api/v1/analytics/chat`
